# Celestia

Esta es la puerta pública de Celestia, una asistente personal que vive en un móvil.

Si Celestia está encendida, desde aquí puedes hablar con ella como visita: solo
charla, y no guarda nada de lo que escribes. Si está apagada, la página te lo dice.

La página es el mismo chat que usa su dueño en casa: Celestia la publica aquí sola
cada vez que arranca (index.html), junto con la dirección de ese día para
encontrarla (direccion.json). No hay nada que construir ni instalar.
